All endpoints require `Authorization: Bearer <token>` unless noted. Conventions, auth, and rate limits: [API authentication](/api).

## Auth

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/auth/whoami` | Current user |
| `PUT` | `/auth/profile/username` | Update the current user's username |
| `PUT` | `/auth/profile/avatar` | Upload the current user's avatar |
| `DELETE` | `/auth/profile/avatar` | Remove the current user's avatar |

Device authorization, browser sessions, password reset, SSO, passkeys, and JWKS public-key distribution are served by the Better Auth identity service under `/api/auth`.

## Registry

Uniform per type - substitute `{type}` with `mcps`, `agents`, `skills`, `hooks`, or `prompts`. `{id}` accepts a UUID or name.

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/{type}` | Submit / create |
| `GET` | `/{type}` | List approved items |
| `GET` | `/{type}/{id}` | Details |
| `POST` | `/{type}/{id}/install` | Generate a harness config snippet |
| `DELETE` | `/{type}/{id}` | Delete |
| `GET` | `/{type}/{id}/metrics` | Usage metrics |
| `POST` | `/agents/{id}/pull` | Resolve an agent and generate its full harness installation |
| `POST` | `/scan` | Bulk-register items from a harness config scan |

Additional route groups cover component sources, component versions, agent versions, bulk submission (`/bulk`), and registry-backed harness model data (`/registry-models`).

## Insights and dashboard

Insight report generation and retrieval (`/insights/…`) and dashboard aggregates (`/dashboard/…`) power `caracal ops insights` and the web UI. Reconciliation support routes live under `/reconcile`.

## Operator and tenant administration

Deployment operation uses `/operator/*` routes and requires an operator JWT context with the `operator` role. Organization and Project administration uses `/orgs/*` routes and is governed by Organization roles (`owner`, `admin`, `member`) and Project roles (`lead`, `user`).

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/operator/settings` | List dynamic settings (sensitive values redacted) |
| `PUT` | `/operator/settings/{key}` | Set a dynamic setting |
| `GET` | `/operator/users` | List deployment users |
| `PUT` | `/operator/users/{id}/role` | Change deployment role |
| `GET` | `/operator/audit-log` | Query deployment audit events |
| `GET` | `/operator/security-events` | Query deployment security events |
| `GET` | `/orgs` | List caller's Organizations |
| `GET` | `/orgs/{org}/projects` | List accessible Projects in an Organization |

Further operator sub-groups cover trace privacy, registered-Agent policy, retention, support bundles, logs, status, resources, AI engine configuration, migration jobs, restart controls, and tenant lifecycle.
